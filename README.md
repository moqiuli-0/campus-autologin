# 校园网自动登录（CampusNetAutoLogin）

安卓后台工具：连接需要网页认证（Captive Portal）的校园网 WiFi 时，自动检测认证页并代填账号密码完成登录，全过程无需手动打开浏览器。

- 纯本地工具：账号密码使用安卓系统级加密仅存本机，**不上传任何服务器**，零统计零埋点
- 非官方学生作品，仅供学习交流与校内自用

## 功能

- **后台自动认证**：前台服务监听 WiFi 连接事件并周期复查；检测到认证页时自动填入账号密码并提交
- **SSID 关键词规则**：在设置中添加你的校园网 WiFi 名称关键词（支持部分匹配、忽略大小写），可随时增删；未配置规则时不会自动登录
- **认证页自动学习**：首次遇到陌生认证页时按页面特征自动识别并记住该 WiFi
- **非校园网保护**：认证页与所配规则不符时**绝不发送账号密码**，并可一键用浏览器打开认证页手动登录
- **手动指认校园网**：关键词没覆盖的 WiFi，可在主页状态卡一键「这是校园网，记住它」，结果写入判断记忆并立即重测
- **位置围栏（可选）**：可采集"学校位置"，自动登录前核对是否在校（默认关闭，仅本地比对不上传）
- **离校模式**：放假离校时一键停止后台监控与开机自启并关闭应用，下次打开自动恢复
- **电脑版登录模拟**：校园网常按"手机版/电脑版"页面各记一台设备，可切换桌面浏览器标识占用电脑版名额
- **检测间隔自定义**（15–3600 秒）、首次连接立即检测
- **通知栏实时状态**（尝试用时/已连接/失败原因）、登录历史、双档位日志与导出
- **主题颜色自定义**（预设 + RGB/HEX）、隐私声明、ADB 授权引导、开机自启

## 使用步骤

1. 安装 APK，首次进入按引导授权（位置权限用于读取 WiFi 名称，通知权限用于失败提醒）
2. 填写校园网账号和密码并保存；在 设置 → 检测 中**添加你的校园网 WiFi 名称关键词**
3. 打开主页「后台监控」开关；建议按 运行环境 检查项完成电池白名单与自启动设置
4. 之后连接校园网 WiFi 即自动登录，无需手动操作
5. 遇到问题：开启 详细日志 → 复现一次 → 导出日志

## 工作原理

1. **网络监听**：前台服务通过 `ConnectivityManager.NetworkCallback` 监听 WiFi 连接事件 + 周期复查
2. **SSID 匹配**：读取当前 WiFi 名称，匹配用户配置的关键词规则
3. **联网探测**：请求多个 `generate_204` 探测点，204 = 已联网；302 重定向 = 被拦到认证页
4. **自动登录**：无头 WebView 打开认证页，JS 自动填表并触发页面自身的登录按钮；失效时兜底直接 POST 表单
5. **结果反馈**：成功静默、失败通知

## 构建

```
gradlew assembleRelease        # 产物：app/build/outputs/apk/release/app-release.apk
gradlew testDebugUnitTest      # 单元测试
```

- minSdk 26（Android 8.0）
- 需要 JDK 17+（本机路径可在 用户目录 `.gradle/gradle.properties` 的 `org.gradle.java.home` 配置）
- 正式签名密钥不入库：根目录放置 `release.keystore` + `keystore.properties`（参考 `signingConfigs` 配置）

## 已知限制

- 尚未在所有校园网环境中验证，认证页结构差异可能导致自动填表失败（会以通知明确提示）
- 安卓系统限制：无法替用户自动切换/连接指定 WiFi；SSID 读取需要位置权限
- 账号密码加密存储使用 androidx.security:security-crypto 1.1.0-alpha06（该库官方已停止演进）；当前功能正常
- 为稳定性考虑暂未开启 R8 混淆，安装包体积偏大（约 7.7MB）
